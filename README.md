# Vision Classification Tuning

> 让 Codex 不只会运行现有配方，还能读懂训练代码，主动发现值得尝试的低成本涨点方向。

## 为什么需要它

很多视觉项目在代码跑通后就直接长时间训练。模型结构通常已经确定，但学习率、预热、调度、标签平滑、数据增强、权重衰减和 EMA 等训练配方仍有较大优化空间。

真正的困难不是缺少“技巧清单”，而是不知道当前项目缺什么、哪些方法与损失和标签语义兼容、哪个候选最值得先测。盲目叠加方法不仅耗费训练时间，还可能让指标下降。

`vision-classification-tuning` 会先读取项目代码、配置和日志，再筛选三到五个高概率方向，明确推荐一个首选。用户授权测试后，只运行少量可归因对照，不展开无边界搜索，也不要求新增网络模块。

## 正面实验结果

> [!TIP]
> **CIFAR-100：标签平滑以很低成本提高 2.23 个百分点**
>
> ResNet34、100 轮、三个配对种子。保持快速训练路径、批量和学习率不变，仅加入标签平滑 0.1，平均验证准确率从 **73.00%** 提升到 **75.23%**。

| 阶段 | 配方 | 三种子平均验证准确率 | 相对原始基线 |
| --- | --- | ---: | ---: |
| 原始基线 | FP32＋批量 128＋学习率 0.1 | 72.03% | — |
| 快速配方 | 批量 512＋学习率 0.1 | 73.00% | +0.97 |
| 低成本涨点 | 快速配方＋标签平滑 0.1 | **75.23%** | **+3.20** |

标签平滑本身的归因应比较后两行：平均提高 **2.23 个百分点**。它只改变分类损失目标，不增加推理模块，额外计算开销很小。

> [!TIP]
> **CIFAR-10：学习率与预热修复大批量精度退化**
>
> ResNet34、100 轮、三个配对种子。批量从 128 增至 512 后，沿用原学习率会使平均验证准确率降至 **91.27%**；把学习率调整为 0.2，并加入五轮预热后，准确率恢复到 **94.03%**。

| 阶段 | 配方 | 三种子平均验证准确率 |
| --- | --- | ---: |
| 原始基线 | 批量 128＋学习率 0.1 | 93.60% |
| 不完整的大批量配方 | 批量 512＋学习率 0.1 | 91.27% |
| 联动优化 | 批量 512＋学习率 0.2＋五轮预热 | **94.03%** |

这一改动不增加网络结构，只调整训练参数；相对未联动的大批量配方提高 **2.76 个百分点**，也略高于原始基线。它说明批量变化后不能只追求吞吐，还要联合检查学习率和预热。

## 它能帮你完成什么

### 读懂当前训练配方

- 读取模型、损失、数据、优化器、学习率、调度、增强和评价代码；
- 检查已有日志更像初期不稳、欠拟合、过拟合还是后期波动；
- 区分普通训练参数与原型、教师、队列等方法特有状态。

### 主动发现候选

- 检查学习率、预热、调度、批量联动和权重衰减；
- 检查标签平滑、RandAugment、MixUp、CutMix 和随机擦除；
- 检查 EMA、SWA、检查点选择、预训练和分层学习率；
- 根据项目代码和现象排序，只展示三到五个高概率方向。

### 低成本验证

- 默认推荐一个首选，不把完整技巧菜单交给用户；
- 短测沿用原完整调度，只在指定进度停止；
- 一次只改变一个候选或一组必须联动的参数；
- 使用项目原有主要指标判断，不用训练损失代替最终效果。

## 调用行为

| 用户请求 | 技能行为 |
| --- | --- |
| “分析怎么涨点” | 读取代码，推荐三到五个方向，然后停止 |
| “测试最推荐的方案” | 自动选择首选并运行一个短程对照 |
| “测试标签平滑” | 检查兼容性并直接验证标签平滑 |
| “比较多个方案” | 明确授权后最多运行两个候选 |
| “短测有效就完整训练” | 按预设门禁继续，否则短测后停止 |

## 快速开始

安装后可以直接对 Codex 说：

```text
使用 $vision-classification-tuning 读取当前项目代码和训练记录，推荐最值得测试的低成本涨点方案。
```

只需要分析时：

```text
分析这个视觉训练项目还有哪些涨点空间，按优先级给出三到五个候选，不启动训练。
```

允许短测时：

```text
选择你最推荐的一个训练配方候选，完成最小改动和短程对照，然后报告是否值得继续。
```

## 安装

### 作为插件安装

```bash
codex plugin marketplace add nnu-sky/vision-classification-tuning
```

刷新插件市场后安装“视觉训练配方优化”。

### 只安装技能

在 Codex 中调用 `$skill-installer`，安装下面的 GitHub 目录：

```text
https://github.com/nnu-sky/vision-classification-tuning/tree/main/plugins/vision-classification-tuning/skills/vision-classification-tuning
```

## 项目兼容性

`AGENTS.md` 不是使用本技能的前置条件。项目已有规则时优先遵守；没有时从训练入口、配置和日志提取约束。

本技能保持网络结构和任务定义不变。纯吞吐、显存、编译和多卡扩展应使用 GPU 工程优化技能；新增模块、架构搜索或手写 CUDA 不属于低成本训练配方优化。

## 证据边界

- 上述结果来自本地三个种子、100 轮验证实验；
- 标签平滑在 CIFAR-100 有效，但没有成为 CIFAR-10 默认项；
- 短测用于筛选候选，不能单独证明完整训练最终有效；
- 具体参数和收益不能直接迁移到其他模型、数据集或任务。
